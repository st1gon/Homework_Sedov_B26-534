# Python Practice - Variant 3

Решение практических задач по основам Python (Вариант 3).

## Структура проекта

- `task1_3.py` — Задача 1: Матрица с шахматным узором
- `task2_3.py` — Задача 2: Самая длинная серия
- `task3_3.py` — Задача 3: Частотный словарь символов
- `task4_3.py` — Задача 4: Разворот матрицы
- `task5_3.py` — Задача 5: Поиск аномалий
- `task6_3.py` — Задача 6: Анализ продаж
- `task7_3.py` — Задача 7: Поиск наиболее похожих строк
- `task8_3.py` — Задача 8: Декоратор повторного запуска
- `task9_3.py` — Задача 9: Товары интернет-магазина
- `task10_3.py` — Задача 10: Планировщик задач
- `main.py` — Точка входа для демонстрации решения всех задач

## Запуск

Запустить демонстрацию всех решений:

```bash
python main.py
```

Каждая задача также может быть запущена отдельно:

```bash
python task1_3.py
```
